Tạo bảng tên để bàn

Gõ nội dung, xem trước ngay, rồi xuất file Word A4 ngang. Mỗi trang có hai mặt giống nhau, mặt trên xoay ngược để gập thành bảng đứng.

Hướng dẫn và lưu ý
  • Bảng tên: mỗi dòng bạn gõ là một dòng trên bảng. Dòng quá dài sẽ tự xuống dòng, cỡ chữ tự co giãn cho vừa khung.
  • Bảng tên lãnh đạo: nhập họ tên và chức vụ. Quốc huy và dòng “ĐỒNG CHÍ” tự có, dòng đầu có thể đổi ở ô phía trên.
  • Chữ luôn được viết hoa. Danh sách được nhớ lại trong trình duyệt lần sau mở.
  • Phông chữ: file Word gốc dùng UVN Huong Que Nang. Nếu máy đã cài phông này, tool tự dùng. Nếu chưa, bấm “Nạp phông chữ…” và chọn file .ttf của phông đó; khi chưa có, tool dùng phông thay thế gần giống.
  • File Word xuất ra chứa ảnh từng bảng tên (giống file gốc của bạn), nền trang đỏ, khổ A4 ngang. Muốn sửa chữ thì sửa ở tool rồi xuất lại.
